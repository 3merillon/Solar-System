# Implemented field engine

This is a finite experimental engine, not a constant-time renderer for unrestricted programs. Rust owns scene state, camera anchoring, GPU buffers, traversal and transport. The browser uses wgpu's **BrowserWebGpu** backend; JavaScript supplies the DOM and input. Native Vulkan is an independent execution target. No canonical mesh, heightmap texture, WebGL or prebuilt planet volume is required. The HDR pipeline and optional experimental temporal reconstruction are documented in [PERFORMANCE.md](PERFORMANCE.md); the current exact optimizations are documented in [PERFORMANCE-SECOND-PASS.md](PERFORMANCE-SECOND-PASS.md).

## Canonical world and derived working set

`solar-core::field::FieldOracle` separates scalar values from conservative segment intervals. The supported program vocabulary is norm/plane/box primitives, linear transforms, min/max/negation CSG, finite cubic lattice spectra, bounded displacement, one explicitly bounded noise warp, and finite bilinear erosion deltas. The implementations are compiled Rust/WGSL functions, not an unrestricted user shader graph. The reference library has no renderer dependency.

The planetary field has 24 directly addressable bands, continental and ridge modes, a separate mesoscale spectrum, and a rough coastal solid with an arch/cave, excavation and disconnected rock. The default radius is 6,371,000 m. The last planetary wavelength is 0.25 m; at default roughness its amplitude is about 9 mm. Coastal features add 0.0625 m wavelength / 12.5 mm amplitude displacement. A 1 mm analytic sheet is a separate visibility test. A millimetre numeric query is **not** a claim that the whole image resolves millimetre geometry.

Sector coordinates are signed 64-bit decimal strings in JSON, with an integer body ID. Hashing includes all sector bits and the body. A body-local camera uses f64 and is limited to ±250 million metres per component; its GPU anchor is split at 4096 m. No universe-wide floating-point position is constructed. Changing sectors changes identity without allocating other bodies. Hash collisions remain possible: seeds are 32 bits.

Each camera constructs 24 compact lattice proxies. Integer cell identity and local polynomial differences avoid subtracting large coarse amplitudes. The first eight bands also have an optional gradient/Taylor proxy with a finite validity radius, curvature remainder and ridge-sign validity check. It is disposable and rebuilt on a cold camera cut. Materials use integer lattice anchors at power-of-two fine scales. The rebase audit compares the same world locations from origins separated by 4096 m, including fine material noise.

## Visibility and bounds

The primary pass walks ray intervals in increasing order. A 64-bit pair of u32 cursor words encodes a dyadic path up to depth 48; there is no exponentially expanded tree or per-ray stack allocation. A hit needs a sign witness on either side and an interval no wider than the requested tolerance. The nearest unresolved prefix is retained. A certified region after a narrow uncertain interval can supply the second sign witness. Loose terminal intervals are retried at finer subdivisions. Tangencies and exhausted work remain unresolved. Depth overflow is explicit.

The tolerance is `max(minimum_metres, distance * pixel_angle * requested_pixels)`. This controls ray depth isolation; it is **not a proof of pixel coverage**, filtered silhouettes or preservation of all subpixel topology. The first water interface terminates the primary solid search; reflected and transmitted rays query independent bounded segments.

Bounds used by the restricted vocabulary:

- Norm along a segment: convexity puts the maximum at an endpoint; clamped orthogonal projection gives the minimum. Diagonal transforms apply to both position and direction. Ellipsoid fields are not claimed to be signed distance fields.
- Union/intersection: interval min/max; difference negates and swaps the subtrahend endpoints. Abs uses zero as its lower bound if the interval crosses zero.
- Cubic lattice noise: corner values in [-1,1], nonnegative weights summing to one, each partial derivative ≤3. Thus the directional bound is `3*sum(abs(direction))`. Diagonal Hessian terms are ≤12 and mixed terms ≤4.5, giving operator norm ≤21; implementation uses 30. A local Taylor range uses `abs(gradient·d)*half + 15*|d|²*half²`, capped by the global range. This remains valid across cells because the cubic interpolant is C1.
- Finite residual: the sum of absolute omitted amplitudes. Ridge modes use the abs interval. The Taylor prefix is used only where no ridge sign can change.
- Correlated Taylor intervals accumulate signed radial and terrain derivatives before taking their absolute value. This preserves cancellation on shallow terrain; Hessian remainders are still summed conservatively. The result is intersected with the independent global/local interval. A 384-region, 6528-sample f64 audit checks three seeds and the coastal CSG features; finite sampling is not a proof.
- The small warped cave uses `1 + 0.35*0.6*3*sqrt(3)` as its spatial Lipschitz envelope. Unbounded/user-defined warps are unsupported.
- Erosion is a fixed-rim bilinear patch. The uploaded maximum displacement and maximum finite differences bound its residual and gradient. The zero rim makes the exterior extension continuous.

Floating-point envelopes are separately added: small fields use `3e-6*(1+|p|+|t|)`; planetary queries use `80 micrometres + 1.5e-6*|local offset|`, plus proxy roundoff. These are engineering envelopes tested against f64, **not formal directed-rounding certificates for every driver**. Reference suites test nearest-root intervals, starts inside, tangencies, multiple crossings, a thin sheet, CSG, seeds, and origin changes. A wider proof of floating-point behavior remains research work.

## Transport and materials

The second compute pass consumes primary visibility, evaluates up to three material layers, and integrates surfaces/interfaces/media. 4096 deterministic global material IDs map into eleven data-driven physical descriptors in `web/materials.json`; they do not allocate 4096 pipelines or textures. Solar-System v2, soil, sediment, wetness and snow use a shared rough dielectric GGX model. Fine grain fades according to footprint, with unresolved variance increasing roughness. This is an approximate filter, not exact integration of geometric microfacets.

Water uses stable analytic interfaces, exact unpolarized dielectric Fresnel reflection/refraction, total internal reflection, medium tracking and RGB Beer absorption. The camera-to-water distance is computed in f64 and uploaded separately, preserving submillimetre crossings even when the sea is kilometres below the datum. Every positive interface distance is retained. Solid-only secondary queries start on the interface without a normal bias that could jump into a shallow floor.

One optical model now covers every footprint. A rejected 20 m footprint switch produced an obvious arc across the ocean. Both reflected and transmitted air paths integrate the same atmosphere/cloud fields from their own origins. Air secondary solid queries have a 100 km extent; submerged queries have a 1500 m extent with Beer attenuation. These are finite limits, and secondary unresolved rays are counted with approximate background fallback. They are not certified complete transport. The diagnostic report exposes them separately from amber primary failures.

Secondary visibility inherits the existing interface footprint as its minimum interval tolerance. It does not restart at the camera's millimetre floor after a long primary path. This is a continuous per-ray quality policy, not a distance-triggered shading switch. The interval algorithm and sign witnesses remain the same; there is still no complete coverage proof for refracted ray cones.

Four world-anchored wave phases evolve with time. The shader projects each full pixel cone onto the water tangent plane and filters wave frequencies before the directional Nyquist limit, including grazing elongation. It checks reflected/transmitted hemispheres against the geometric interface. This animates optical surface normals; the mean water geometry remains analytic, without displaced wave silhouettes or fluid simulation. Cloud density is advected by a configurable wind. A fixed time produces repeatable images and benchmarks force time zero; presets retain animation time. The browser renders continuously while animation is enabled and can pause it.

Air and cloud density share body coordinates and a segment partition at atmosphere/cloud shells. Deterministic finite quadrature integrates additive extinction and single scattering against space and a finite sun disk. Variable cloud tops and a named diffuse cloud illumination term approximate multiple scattering; rock uses a diffuse sky fill. Twelve 300 m solar samples resolve cloud edges, followed by a coarser air path; clear-air queries use six samples. An analytic planetary horizon and optional local solid queries supply sun occlusion. Water excludes atmospheric integration inside its medium. Advection is not a weather simulation.

The optical policy does not silently skip a positive-density region based on extinction alone. `solar-core::optics` requires an incoming illumination bound and phase bound before producing a radiance error bound. The rendered quadrature uses an explicit sample budget, not a claimed rigorous radiance tolerance. The audit compares it against 128 samples and compares shared sampling with independent air/cloud walks at identical sample locations and lighting. The latter is a controlled traversal experiment, not a comparison with another production renderer.

## Durable erosion

The 65×65, 8 m grid covers a 512 m coastal basin. Priority flood creates a downstream DAG across depressions; rain, stream-power capacity, suspended sediment, deposition, evaporation and thermal creep advance deterministic steps. Rim heights remain fixed; outlets export sediment. A solid + suspended + exported ledger checks conservation. This is a finite local simulation, not planet-wide hydrology or a claim of hydrologically continuous independently simulated tiles.

Version 2 snapshots include full height, original terrain, water, sediment, drainage, catchment, exported mass, step and generator settings. Import validates size, finiteness, identity, fixed boundaries, drainage and conservation. `serde_json` uses float-roundtrip parsing; save/reload/resume is tested exactly. The browser can save/load snapshots; `tools/Erode.ps1` provides an offline workflow. Presets store procedural settings; snapshots store actual durable simulation state.

## Budgets and accounting

The default path has visibility, cloud lattice construction, linear-HDR transport and spatial reconstruction compute dispatches, then presentation. Cloud construction is skipped when clouds are disabled. Workgroups remain 8×8 for image passes. No subgroup or hardware ray-tracing feature is required. Ordinary rendering performs no image/counter readback; optional profiling maps a bounded timestamp ring. Internal and output images each have a 2,073,600-pixel cap. Visibility records cost 32 bytes/internal pixel, HDR another 8, display 4 bytes/output pixel, and reserved capture storage another padded 4. CPU basin arrays, proxies, material descriptors and timing/counter payloads are counted; driver allocations, shader-private storage, pipelines, swapchain surfaces and capture copies are excluded. Browser default controlled storage is 108,460,260 bytes at 1080p, including the 8 MiB lattice allocation. Native AA uses 241,170,744 bytes. Optional histories and their limits are itemized in [PERFORMANCE.md](PERFORMANCE.md#memory-and-reproduction), with current cache accounting in the second-pass report.

Global counters emulate u64 addition with pairs of atomics, including secondary queries. Band counters cover visibility spectrum work and conservatively charge four coastal bands when applicable; shading field/normal evaluations, material and optical noise are outside this counter and are included in the transport GPU time. The interval-depth high-water field retains the historical JSON name `stack_high_water`. CPU proxy and erosion construction, GPU pass timestamps and submission/readback wall time are separate. Optional timestamp absence falls back to explicitly labelled submission/readback time.

Interactive rendering defaults to one pending submission; the experimental API allows two. The frame uniform is 432 bytes, including previous-camera rebasing, jitter, output spacing, history/reset state and reference crop bounds. Configuration/resize checks a provisional 256 MiB steady controlled-payload cap before mutation. That is not a total-VRAM or transient resize-overlap guarantee.

Performance still depends on visible topology, grazing angle, roughness, material/transport work and requested error. A finite work budget only makes failure bounded. No constant-time or 60 fps claim is made.

## Exact second-pass caches and specialization

`exact_work=true` reads the unchanged 24 geological proxies through a fixed uniform array backed by the existing 1,920-byte allocation. It also eliminates zero-support cloud noise and already-occluded outside-layer solar integration, specializes planetary pipelines, and supplies unchanged solar loop counts through frame uniform lanes. `exact_work=false` retains the control path. The finite quality suite found identical HDR and display output; this is not a cross-driver bit-identity guarantee.

`noise_cache=true` allocates eight 64³ integer lattice windows (8 MiB). Every submitted planetary cloud frame rebuilds them at the current camera, body, seed and wind epoch. Cached entries are the original hash values; world coordinates, eight-corner cubic interpolation and sample counts are unchanged. Queries outside the window use the original hash. Transport timestamps include the build. The experimental solar grid bypasses this cache and owns its original 2 MiB allocation. Both disabled returns to a 16-byte placeholder. Admission checks and lifecycle tests cover these transitions.

`prefix_cache=false` remains a rejected experiment. Its per-ray Taylor certificate encloses coarse spectral reuse, with fine bands, CSG and erosion explicit. An audit found that the older coastal support shortcut preserves the intended sign but not the full CSG scalar outside its box. The experimental prefix path now encloses both scalar definitions there; the independent oracle was not relaxed. Finite bound tests pass, but retrying uncertain cached intervals increased work and time. This candidate is not a default acceleration structure or a formal floating-point proof.
